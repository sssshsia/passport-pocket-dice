# passport-pocket-dice v0.2

发布准备日期：2026 年 11 月 3 日。本文不代表已完成 GitHub 发布。

## 相比 v0.1 的变化

- 项目改名为 `passport-pocket-dice`，内嵌版本改为 `0.2`。
- 投掷页和历史页使用 `1粒 点数4 骰子` 等中文数量与点数描述。
- 单粒骰子或硬币在原行水平居中；多粒排列保持不变。
- D4 动画和结果改用圆点骰面，与 D6 的显示方式一致。
- 新增 D200，总和最高 1200，保留 D10 和 D100。
- 底部提示改为 `长按确定改数量 下键查记录`，查历史仍需长按下键。
- 推送 tag 只构建产物，不自动发布。CI 发布需在 tag 上单独手动运行并启用
  `publish_release`；发布本地实测镜像则另行上传，使用该镜像而非 CI 新构建。

## 固件与使用

使用 **`passport-pocket-dice-full.bin`**，这是适用于
**ESP32-C3 / 8 MB Flash** 的 860064 字节合并镜像，从 **`0x0`** 刷写。
应用单镜像 `.bin` 不适用于该偏移。
合并刷写可能重置 NVS/PHY 数据，无需整片擦除。

已实测本地固件的 SHA-256：

```text
128ab7eafbf610e383025a0572b3d29d4d868c7d7f9103a5a6e8c2b9319a01f8
```

短按上下键选择骰型，确定键投掷；长按确定改数量，长按下键查历史。
硬币数量固定为一。完整操作及休眠行为见[应用说明](../dice-app.zh_CN.md)。

## 构建

激活 ESP-IDF 5.5.3，使用锁定依赖：

```sh
./tools/validate.sh --static
./tools/validate.sh --firmware
```

合并固件输出为 `build/passport-pocket-dice-full.bin`。
Windows 如遇 ESP-IDF 拒绝 MSYS，使用[应用说明](../dice-app.zh_CN.md)
中的原生 PowerShell 替代方式。

## 验证与限制

- Build：PASS，原生 ESP-IDF 5.5.3 构建，合并镜像内容、分区布局及 ELF 对应关系已验证。
- Host tests：PASS，覆盖全部类型和数量、D4 圆点、D200 边界、163 字符字形覆盖和
  900 次 UI 页面切换。Windows 跳过了 21 项已有的文件系统/符号链接测试。
- Device tests：刷写校验与 25 秒启动观察通过，未发现崩溃标记；使用者随后反馈工作正常。
- Unverified：休眠唤醒时序、实际电流及长期稳定性尚未专项验证。
  完整 shell 门禁受 MSYS 限制中止；原生固件与静态验证分别通过。

以上设备结果对应上述哈希。重新运行 CI 可能产生不同哈希的固件，
不能自动沿用这份确切二进制的实测结论。
