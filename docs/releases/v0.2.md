# passport-pocket-dice v0.2

Release preparation: November 3, 2026. This document does not assert that a
GitHub release has already been published.

## Changes since v0.1

- Renamed the project to `passport-pocket-dice`, embedded version `0.2`.
- Replaced abbreviated quantity/type captions with Chinese quantity and
  face-count descriptions on the roll and history pages.
- Centered the die or coin horizontally when quantity is one, preserving its
  original row and the multiple-dice layout.
- Added D4 pip faces for animation and results, matching D6's presentation.
- Added D200 and totals up to 1200; retained D10 and D100.
- Updated the footer's quantity/history wording. History still requires holding DOWN.
- Tag pushes build an artifact without publishing. CI publishing requires a
  separate manual run on a tag with `publish_release` enabled. Publishing the
  tested local image uses a separate upload instead of that fresh CI build.

## Firmware and use

Use **`passport-pocket-dice-full.bin`**, the merged 860064-byte image for
**ESP32-C3 / 8 MB Flash**, and flash it from **`0x0`**.
The app-only `.bin` is not suitable for that offset.
Merged flashing may reset NVS/PHY data; a whole-chip erase is unnecessary.

The tested local image has SHA-256:

```text
128ab7eafbf610e383025a0572b3d29d4d868c7d7f9103a5a6e8c2b9319a01f8
```

Tap UP/DOWN to select the type and OK to roll. Hold OK to change quantity;
hold DOWN to open history. A coin always has quantity one.
See the [application guide](../dice-app.md) for all controls and sleep behavior.

## Build

With ESP-IDF 5.5.3 activated and the pinned dependencies:

```sh
./tools/validate.sh --static
./tools/validate.sh --firmware
```

The merged image is produced at `build/passport-pocket-dice-full.bin`.
On Windows, use the native PowerShell fallback described in the
[application guide](../dice-app.md) if ESP-IDF rejects MSYS.

## Verification and limits

- Build: PASS, native ESP-IDF 5.5.3; merged bytes, partition layout and ELF
  correspondence verified.
- Host tests: PASS, including all types/quantities, D4 pips, D200 boundaries,
  163-character font coverage and 900 UI page transitions. Windows skipped
  21 existing filesystem/symlink test cases.
- Device tests: write verification and a 25-second startup observation passed;
  no crash markers. The owner subsequently reported normal operation.
- Unverified: dedicated sleep/wake timing, current measurements and long-term
  stability. The combined shell gate was blocked by MSYS; native firmware
  and static validation passed separately.

These hardware results identify the hash above. A new CI build may have a
different hash and must not inherit those exact-binary test results automatically.
The existing local `v0.2` tag identifies firmware source commit `771cbc4`.
Release-preparation documents are being reviewed separately; the tag has not
been moved as part of preparing these notes.
